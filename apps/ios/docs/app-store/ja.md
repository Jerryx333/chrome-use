## Subtitle
デスクトップのAIエージェントを操作

## Promotional text
iPhoneからタスクを開始し、デスクトップのエージェントの作業を見守り、リクエストを承認できます。エージェントとサインイン済みのChromeはコンピュータ上で動き続けます。

## Description
chrome-use Remote は、コンピュータで動く chrome-use エージェントパネルを操作するための iPhone 用リモコンです。会話を開始し、サインイン済みの実際の Chrome でエージェントが作業する様子を追いかけ、外出先からでも承認リクエストに対応できます。

すべての処理はあなた自身のコンピュータで行われます。iPhone は Tailscale ネットワーク、ご自身の Cloudflare トンネル、またはローカルネットワーク経由でコンピュータに直接接続し、間に chrome-use のサーバは存在しません。すべてのメッセージは、iPhone とコンピュータだけが持つ鍵でエンドツーエンド暗号化されます。

- すぐにペアリング：`chrome-use mobile pair` を実行して QR コードをスキャンするだけです。
- 会話：Claude Code、Codex など普段使っているエージェントで新しい会話を開始。テキストと最大5枚の画像を送信し、進行状況をリアルタイムで確認し、ターンを停止できます。
- 承認：エージェントが何をしようとしているかを正確に確認し、許可または拒否できます。エージェントからの質問にも iPhone からそのまま回答できます。
- 通知：エージェントが対応を求めたときや作業が完了したときに通知します。通知の内容はコンピュータ上で暗号化され、プッシュサービスは暗号文を中継するだけです。
- スクリーンショット：エージェントのブラウザタブをいつでも確認できます。
- スケジュール：スケジュールされたタスクを今すぐ実行したり、オン／オフを切り替えたりできます。
- 複数のコンピュータに対応。Face ID ロック（オプション）と9つの言語にも対応しています。

iPhone にコンピュータが許可する以上の権限が与えられることはありません。iPhone から開始した会話ではコマンドを実行できず、フルアクセスはデスクトップ側で有効にしない限りコンピュータ上だけに限られます。

Mac、Windows、または Linux コンピュータ上の chrome-use が必要です。14日間無料でお試しいただけ、その後は1回限りの購入でご利用いただけます。
