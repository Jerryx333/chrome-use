# App Store listing — German (de-DE)

## Name
chrome-use Remote

## Subtitle
Deinen Desktop-Agent steuern

## Promotional text
Starte Aufgaben, sieh deinem Desktop-Agent bei der Arbeit zu und gib seine Anfragen vom iPhone aus frei. Agent und angemeldetes Chrome bleiben auf deinem Computer.

## Description
chrome-use Remote ist die Fernbedienung für das chrome-use Agent-Panel auf deinem Computer. Starte eine Konversation, verfolge, wie der Agent in deinem echten, angemeldeten Chrome arbeitet, und beantworte seine Freigabeanfragen, wo immer du gerade bist.

Alles läuft auf deinem eigenen Computer. Das iPhone verbindet sich direkt über dein Tailscale-Netzwerk, deinen eigenen Cloudflare-Tunnel oder dein lokales Netzwerk – ohne chrome-use Server dazwischen. Jede Nachricht ist Ende-zu-Ende-verschlüsselt, mit Schlüsseln, die nur dein iPhone und dein Computer besitzen.

- In Sekunden gekoppelt: `chrome-use mobile pair` ausführen und den QR-Code scannen.
- Konversationen: Starte neue mit Claude Code, Codex und den anderen Agents, die du nutzt, sende Text und bis zu fünf Bilder, verfolge den Fortschritt live und stoppe einen Durchlauf.
- Freigaben: Sieh genau, was der Agent tun möchte, und erlaube oder lehne es ab; Rückfragen des Agent beantwortest du direkt auf dem iPhone.
- Mitteilungen: Erfahre, wann der Agent dich braucht oder fertig ist. Die Inhalte werden auf deinem Computer verschlüsselt; unser Push-Dienst leitet nur Chiffretext weiter.
- Bildschirmfotos: Sieh dir den Browser-Tab des Agent bei Bedarf an.
- Zeitpläne: Führe eine geplante Aufgabe sofort aus oder schalte sie ein oder aus.
- Mehrere Computer, optionale Face ID-Sperre und neun Sprachen.

Dein iPhone bekommt nie mehr Rechte, als dein Computer erlaubt: Vom iPhone gestartete Konversationen können keine Befehle ausführen, und voller Zugriff bleibt dem Desktop vorbehalten, solange du ihn dort nicht freigibst.

Erfordert chrome-use auf einem Mac-, Windows- oder Linux-Computer. 14 Tage kostenlos testen, danach einmaliger Kauf.
