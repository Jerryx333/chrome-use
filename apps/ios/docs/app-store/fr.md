# App Store listing — French (fr-FR)

## Name
chrome-use Remote

## Subtitle
Pilotez votre agent à distance

## Promotional text
Lancez des tâches, suivez votre agent et validez ses demandes depuis votre téléphone. L’agent et votre Chrome connecté restent sur votre ordinateur.

## Description
chrome-use Remote est la télécommande mobile du panneau d’agent chrome-use installé sur votre ordinateur. Lancez une conversation, suivez l’agent pendant qu’il travaille dans votre vrai Chrome, déjà connecté à vos comptes, et répondez à ses demandes d’accord où que vous soyez.

Tout fonctionne sur votre propre ordinateur. Le téléphone s’y connecte directement via votre réseau Tailscale, votre propre tunnel Cloudflare ou votre réseau local ; aucun serveur chrome-use ne se trouve entre les deux. Chaque message est chiffré de bout en bout avec des clés que seuls votre téléphone et votre ordinateur détiennent.

- Jumelage en quelques secondes : exécutez `chrome-use mobile pair` et scannez le code QR.
- Conversations : lancez-en avec Claude Code, Codex et les autres agents que vous utilisez, envoyez du texte et jusqu’à cinq images, suivez la progression en direct, arrêtez un tour.
- Demandes d’accord : voyez exactement ce que l’agent veut faire, puis autorisez ou refusez ; répondez à ses questions directement sur le téléphone.
- Notifications : soyez prévenu quand l’agent a besoin de vous ou a terminé. Leur contenu est chiffré sur votre ordinateur ; notre service push ne relaie que des données chiffrées.
- Captures d’écran : affichez à la demande l’onglet de navigateur de l’agent.
- Tâches planifiées : exécutez-en une immédiatement, activez-la ou désactivez-la.
- Plusieurs ordinateurs, verrouillage Face ID facultatif et neuf langues.

Votre téléphone n’obtient jamais plus de droits que votre ordinateur ne lui en accorde : les conversations lancées depuis le téléphone ne peuvent pas exécuter de commandes, et l’accès complet reste sur l’ordinateur, sauf si vous l’y activez.

Nécessite chrome-use sur un ordinateur Mac, Windows ou Linux. Essai gratuit de 14 jours, puis achat unique.
