## Promotional text
用手機開始任務、即時查看電腦上的 agent 工作進度，並隨時核准它的請求。agent 與你已登入的 Chrome 都留在自己的電腦上。

## Description
chrome-use Remote 是電腦上 chrome-use agent 面板的手機遙控器。你可以開始新對話、看著 agent 在你已登入的真實 Chrome 中工作，並在任何地方回覆它的核准請求。

一切都在你自己的電腦上執行。手機透過你的 Tailscale 網路、你自己的 Cloudflare 通道或區域網路直接連到電腦，中間沒有任何 chrome-use 伺服器。每則訊息都經過端對端加密，金鑰只存在你的手機和電腦上。

- 幾秒完成配對：執行 `chrome-use mobile pair`，掃描 QR 碼即可。
- 對話：使用 Claude Code、Codex 或你慣用的其他 agent 開始新對話，傳送文字及最多五張圖片，即時查看進度，也能隨時停止。
- 核准：清楚看到 agent 想做什麼，再決定允許或拒絕；agent 提出的問題也能直接在手機上回答。
- 通知：agent 需要你或完成工作時立即通知你。通知內容在電腦上加密，我們的推播服務只轉送密文。
- 截圖：隨時查看 agent 正在使用的瀏覽器分頁。
- 排程：立即執行排程任務，或將其開啟、關閉。
- 支援多台電腦、可選用的 Face ID 鎖定，支援繁體中文、簡體中文、英文和日文。

手機的權限絕不會超過電腦允許的範圍：從手機開始的對話無法執行指令，完整權限只保留在電腦端，除非你在電腦上開啟。

需要在 Mac、Windows 或 Linux 電腦上安裝 chrome-use。可免費試用 14 天，之後一次性購買。
