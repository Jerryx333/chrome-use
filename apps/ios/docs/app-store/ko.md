# App Store listing — Korean (ko)

## Name
chrome-use Remote

## Subtitle
휴대폰으로 데스크톱 에이전트 조작

## Promotional text
휴대폰에서 작업을 시작하고, 데스크톱 에이전트가 일하는 모습을 지켜보고, 승인 요청에 바로 응답하세요. 에이전트와 로그인된 Chrome은 내 컴퓨터에 그대로 있습니다.

## Description
chrome-use Remote는 컴퓨터에서 실행 중인 chrome-use 에이전트 패널을 위한 휴대폰 리모컨입니다. 대화를 시작하고, 로그인된 실제 Chrome에서 에이전트가 작업하는 과정을 따라가며, 어디서든 승인 요청에 응답할 수 있습니다.

모든 작업은 내 컴퓨터에서 실행됩니다. 휴대폰은 Tailscale 네트워크, 직접 구성한 Cloudflare 터널 또는 로컬 네트워크를 통해 컴퓨터에 직접 연결되며, 중간에 chrome-use 서버를 거치지 않습니다. 모든 메시지는 휴대폰과 컴퓨터만 가진 키로 종단 간 암호화됩니다.

- 간편한 페어링: `chrome-use mobile pair`를 실행하고 QR 코드를 스캔하면 끝입니다.
- 대화: Claude Code, Codex 등 사용 중인 에이전트로 새 대화를 시작하고, 텍스트와 최대 5장의 이미지를 보내고, 진행 상황을 실시간으로 확인하고, 작업을 중단할 수 있습니다.
- 승인: 에이전트가 무엇을 하려는지 정확히 확인하고 허용하거나 거부하세요. 에이전트의 질문에도 휴대폰에서 바로 답할 수 있습니다.
- 알림: 에이전트가 확인을 요청하거나 작업을 마치면 알려 드립니다. 알림 내용은 컴퓨터에서 암호화되며, 푸시 서비스는 암호문만 전달합니다.
- 스크린샷: 필요할 때 에이전트의 브라우저 탭을 확인하세요.
- 예약 작업: 예약된 작업을 지금 바로 실행하거나 켜고 끌 수 있습니다.
- 여러 대의 컴퓨터, 선택 사항인 Face ID 잠금, 9개 언어를 지원합니다.

휴대폰은 컴퓨터가 허용한 것 이상의 권한을 갖지 않습니다. 휴대폰에서 시작한 대화는 명령을 실행할 수 없으며, 전체 권한은 데스크톱에서 직접 켜지 않는 한 데스크톱에만 남아 있습니다.

Mac, Windows 또는 Linux 컴퓨터에 chrome-use가 설치되어 있어야 합니다. 14일 동안 무료로 사용해 본 후 한 번만 구입하면 됩니다.
