## Promotional text

## Description
chrome-use Remote 是电脑上 chrome-use agent 面板的手机遥控器。发起对话，看 agent 在你真实、已登录的 Chrome 里一步步操作，人在外面也能处理它的审批请求。

所有东西都跑在你自己的电脑上。手机通过你的 Tailscale、你自己的 Cloudflare tunnel 或同一局域网直接连过去，中间没有 chrome-use 的服务器。每条消息都端到端加密，密钥只在你的手机和电脑上。

- 几秒配对：在电脑上运行 `chrome-use mobile pair`，扫二维码。
- 对话：用 Claude Code、Codex 等 agent 新建对话，发文字和最多 5 张图片，实时看进度，随时停止。
- 审批：看清 agent 想做什么，再允许或拒绝；agent 提的问题直接在手机上回答。
- 通知：agent 需要你或完成时提醒你。通知内容在电脑上加密，推送服务只转发密文。
- 截图：随时看 agent 正在用的浏览器页面。
- 定时任务：立即运行，或开关某个定时任务。
- 支持多台电脑、可选的面容 ID 锁，支持简体中文、繁体中文、英文和日文。

手机拿到的权限永远不超过电脑允许的范围：手机上新建的对话不能运行命令，完全访问只在电脑上开启。

需要在 Mac、Windows 或 Linux 电脑上安装 chrome-use。可免费试用 14 天，之后一次性购买。
